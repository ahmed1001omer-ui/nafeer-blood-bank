# Nafeer Blood Bank - Desktop Offline Architecture

نظام إدارة بنك الدم المركزي (نفير) - وضع سطح المكتب أوفلاين

## كيفية عمل النظام بدون إنترنت (Offline Mode):
1. عند تشغيل اختصار البرنامج على سطح المكتب:
   - يقوم المشغل بفحص الخادم المحلي على المنفذ `3000`.
   - إذا لم يكن الخادم يعمل، يتم تشغيله آلياً في الخلفية مع قاعدة البيانات المحلية `blood-bank-test.db`.
   - يتم فتح نافذة التطبيق المستقلة دون شريط متصفح لتبدو كتطبيق Windows أصلي.
2. جميع العمليات من تسجيل دخول، إضافة متبرعين، فحوصات مخبرية، إدارة مخزون، وصرف الدم، وتصدير التقارير تعمل 100% بدون إنترنت.

## ملفات التشغيل:
- `Launch-Nafeer-Desktop.vbs`: مشغل صامت يفتح التطبيق مباشرة دون نوافذ سوداء (مرتبط باختصار سطح المكتب).
- `Launch-Nafeer-Desktop.bat`: مشغل مرئي بالطرفية يُظهر حالة تشغيل الخادم والمنفذ.
- `Start-Offline-Server.bat`: بدء تشغيل الخادم المحلي.
- `Stop-Offline-Server.bat`: إيقاف الخادم المحلي.
- `Create-Desktop-Shortcut.ps1`: تحديث اختصار سطح المكتب وربطه بالأيقونة الجديدة.
